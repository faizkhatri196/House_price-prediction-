
# House Price Prediction from Scratch

A beginner-friendly Machine Learning project that predicts house prices using **Linear Regression implemented from scratch in Python (NumPy)** — without using any ML libraries.

## 📌 Overview

This project demonstrates the core principles of Machine Learning by building a model that learns to predict house prices using only basic math and code. You’ll learn:

✔ How to load and preprocess data  
✔ Why feature normalization matters  
✔ How gradient descent minimizes cost  
✔ How to visualize learning with cost plots  
✔ How to make predictions from the trained model

---

## 🧠 Concepts Covered

- Supervised Learning  
- Hypothesis function  
- Cost Function (Mean Squared Error)  
- Gradient Descent  
- Feature Scaling / Normalization  
- Model Prediction
